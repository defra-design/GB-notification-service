Import notification service

Importers and import agents need to use this service to notify authorities about some goods they import to Great Britain.

{{ govukInsetText({ text: "The import of products, animals, food and feed system (IPAFFS) is no longer in use. You need to use this service instead." }) }}

Which goods need notifying

From an EU country:

  • live animals, such as livestock, pets, wild animals and zoo animals
  • germinal products: animal semen, ova and embryos
  • high-risk plant products: seed and ware potatoes, wood and bark, and plants for planting

For high-risk plant products, this also applies to goods from Norway, Switzerland and Liechtenstein.

From any country:

  • wild marine fish, cephalopods and crustaceans

For all other goods from non-EU countries, use TRACES, the EU system for imports and exports.

If you're not sure, check if you need to submit an import notification before you start.
